# Supplementary evidence

Injection retrieval and depth distortion are synthetic-signal sensitivity measures, not planetary purity. The bootstrap resamples 30 whole stars; repeated phases are not independent stars. Intervention changes concern deterministic software output, not astrophysical causation. Duration values in the intervention figure are days.

Ranking labels called planet by the pipeline include PC-only candidates. The separate reference-group table distinguishes these from CP/KP systems. The predefined primary comparison retains its original combined reference group; the CP/KP breakdown is supplementary. Signal matches require explicit ephemeris/time-system checks and do not constitute new planet validation.
